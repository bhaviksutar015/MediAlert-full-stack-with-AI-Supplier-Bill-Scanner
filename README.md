# MediAlert — AI-Powered Medicine Inventory & Expiry Management

A full-stack web application designed for medical shops to manage medicine
inventory, monitor expiry dates, and reduce manual data entry using
AI-powered supplier bill scanning.

## 🚀 Live Demo

[Open MediAlert]https://medi-alert-full-stack-with-ai-supplier-bill-scanner-8ip4ai5c6.vercel.app/login)

## 📌 About the Project

MediAlert helps medical shop owners manage their medicine inventory and
identify medicines approaching expiry.

The application provides user authentication, medicine inventory management,
expiry monitoring, dashboard insights, and an AI-powered supplier bill scanner
that extracts medicine information from uploaded bills.

## ✨ Key Features

- 🔐 User Authentication & Authorization
- 💊 Medicine Inventory Management
- 📅 Medicine Expiry Monitoring
- 🤖 AI-Powered Supplier Bill Scanner
- 📄 Automatic extraction of medicine/invoice information
- 📊 Dashboard for inventory insights
- 👤 User-specific inventory data
- 📱 Responsive interface
